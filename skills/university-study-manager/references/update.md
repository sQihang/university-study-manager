# 安装与更新说明

当前未提供公开发布地址，不伪造下载链接。分发ZIP只包含`SKILL.md`、`agents/`、`assets/`、`references/`和`scripts/`，不包含测试资料、工作区、私密配置或Token。

本版新工作区采用编号目录与结构版本2，旧版结构保持可用；初始化创建 `00-待整理` 和 `归档说明.md`，已有工作区可补建这两项而不迁移分类目录。01-资料库完整归档、90-辅助数据按需生成；取消全量状态和区域清单，任务现场查找资料，单一 `_来源.json` 分别追踪每次归档去向和机读成果来源。旧账本在首次归档时升级且保留已有成果记录。PDF先提取文字层，必要时再光栅化OCR；复杂表格优先保留静态HTML。OCR入口可恢复已下载结果并报告实际失败阶段，同源成果可在临时区核验后安全替换。

学期看板继续使用schema v2 JSON，课表按大节定位并真实显示连堂跨度；总览会分轨展示同一时段的不同周安排。课程热力图增加周合计和学期统计，待排事项存在时不把空白误写成确定无课。页面保留逐周查看、统一学期尺度统计和单周／全学期PNG导出。离线答题页支持点击或拖拽选择题库文件。

包内不含Poppler、MinerU CLI、Office、Python运行时或真实API Key。缺少工具时提供配置和安装选择。工作区按新结构创建；首版不提供旧工作区自动迁移。
