# 规则自测题

现场查找用户指定规则的机读全文和适用版本；只有人读原文时进入文档处理流程。适用性未知要说明。识别不清、缺页或冲突内容不用于需要唯一答案的题目。

默认生成10至20道判断、单选或多选题；条款不足时少出，不换句凑数。题目在前，答案、解析和依据集中在后。题干保留对象、前提、例外和时间限制；逐题复算答案，检查否定词、数字及选项互斥性。同一生成者复算属于自查，不能标为独立 AI 复核。

默认输出JSON题库，保存在`02-自测/01-题库/YYYYMMDD-主题-01.json`，同日同主题顺延编号，不覆盖。答题页`02-自测/答题.html`离线运行，题库由用户点击选择或拖入页面，不会自动扫描本地目录；页面支持判分、错题、导入导出记录和打印。文件按钮使用悬浮及无障碍说明。错误反馈采用与正确反馈相同的单实线结构，分别使用低饱和红、绿区分。

题库结构版本为1，包含题库ID、标题、规则版本、适用范围、来源，以及每题的类型、题干、选项、答案、解析和来源位置。判断题固定A“对”、B“错”；单选一个答案，多选至少一个答案。所有用户内容作为JSON字符串转义，不插入HTML。

题库文件本身携带完整来源信息，不再维护`题库清单.yaml`。规则更新时生成新题库版本，不静默覆盖旧文件。用户指定TXT时生成一个UTF-8无BOM文件，仍在正文中列全来源和依据。交付题库和答题页路径，默认不把整份题目复制到对话。

交付时按入口规则提示对照原文核对题干前提、答案、解析及条款依据，复用题库已有来源位置；可建议另开 AI 会话或由独立子 Agent 复核纠错。保留题库结构版本1和现有答题页，不新增核验字段或把提示插入机读协议。
