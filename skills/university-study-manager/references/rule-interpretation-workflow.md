# 规则解读

## 检索与适用范围

根据问题现场扫描相关`01-资料库/01-学校资料`主题目录、`90-辅助数据/学校资料`和必要的个人学业资料。旧工作区按其结构版本映射原目录。优先使用已有机读成果；只有归档原文且当前未获读取授权时，先进入文档处理流程。说明实际查找范围，未找到不等于规则不存在。

核对发布主体、适用对象、生效时间、正文与附件，以及学校大纲、学院细则、补充或并行文件的关系。新版只有明确整体替代依据时才使旧版失效。适用性无法确定时使用“如果该文件适用”的条件分析，并请用户或学校核实。

## 提取与核验

凝练政策可以去除套话，但忠实全文保留具体条件、计算式、例外、程序和定义；长文件建立结构化全文及可追溯提要。提要逐条回查原文，关键文件可进行独立复核。用户线下笔记原样归档，其内容在机读规则中标为“用户记录”，不能冒充政策条款。

复杂表格优先读取保留单元格结构的静态HTML。表格展平、缺页或OCR模糊处不用于唯一结论。引用注明文件、条款、标题、页码或稳定记录位置。

GPA、均分和学分进度必须使用适用文件规定的课程范围、等级换算、权重、统计期间及舍入规则。成绩单记载值与推导值分开。单学期结果只描述该学期，不代表推免、评优或毕业常用的累计结果。映射不足时只计算可成立的子集，不称为总体结果。

课程或条款尚未匹配，只能报告当前范围尚未匹配。不得由培养方案中没有同名课程推断其不计入必修、限选、毕业或推免口径。

## 输出

交付规则解读时显著写明一次：**政策解读功能不能替代真人通读政策原始文件，建议结合阅读与AI使用。** 与入口的交付提示合并，链接原文并指出本次应核对的适用对象、条件、例外、时间或公式；可建议另开 AI 会话或由独立子 Agent 复核。同次交付不在开头、结尾重复提醒，长期保存的提要可在来源说明区保留一次。

区分文件事实、用户记录、计算结果和未知项；紧邻关键结论给出来源。默认在对话回答，用户明确要求长期保存时才生成衍生解读文件并登记来源。可以提出需要核实的事项，不生成申请策略或资格保证。
